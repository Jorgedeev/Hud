> Hud básico para MTA:SA:

- Hora del juego (Formato 24h).
- Barra de Salud y Armadura.
- Arma en Mano + Balas (Armas cuerpo a Cuerpo no muestra balas).
- Dinero en mano y Dinero de Banco.
- Nivel de Busqueda por Estrellas.
- Porcentaje de Hambre y Sed.
